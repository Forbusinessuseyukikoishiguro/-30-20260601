# 🐰 うさうさクイズ大会（TOYBOX）｜README

受講生が口頭で出題・回答し、講師は30秒タイマーと正誤記録だけに集中できる、単一HTMLのクイズ進行ツールです。問題の事前登録は不要。研修の小休止やアイスブレイク、理解度の即時チェックに使えます。

---

## 使い方

1. HTMLファイルをブラウザで開く（インターネット接続不要）。
2. タイマー上部で **15秒 / 30秒** を選ぶ（既定30秒）。
3. 受講生が口頭で問題を出す → 「▶ スタート」で計測開始。
4. 受講生が口頭で回答 → 指名メモ（任意）を入れて **⭕ 正解 / ❌ 不正解** を押す。
5. 押すとスコアが更新され、タイマーは自動で初期値に戻る。次の問題へ。
6. 最後に「📋 結果コピー」で、正解率つきサマリーと全問一覧をコピーできる。

操作は講師がするのは「スタート」と「⭕／❌」だけ。出題も回答も受講生が口頭で行います。

---

## 画面の要素

- **スコアボード**：出題数 / ⭕正解 / ❌不正解 をリアルタイム表示。
- **タイマー**：円形リングが減り、残り10秒で橙、5秒で赤＋バウンド、0秒で「時間切れ」。スタート / ストップ / リセット。
- **指名メモ（任意）**：役割表記で入力（氏名は書かない）。空欄でも記録可。
- **記録リスト**：Q番号・⭕❌・指名を新しい順に表示。「1つ取消」「結果コピー」「全リセット」。
- **遊び心**：正解で紙吹雪、ときどき背景にうさぎがひょっこり登場 / 積み木遊び。

---

## 運用ルール

- 指名メモは **役割表記**（受講生A など）。受講生本人を特定する氏名は書かない。
- 記録はコピーして質問ダッシュボード等に貼り付け可能。個人情報は残さない運用とする。
- 答えに詰まったら「確認してお返事いたします」で対応（受講生に「私も勉強中なので」とは言わない）。

---

## 技術仕様

- **形態**：単一HTMLファイル（HTML/CSS/JSすべて内包）。外部リソース読み込みなし。
- **フォント**：端末標準フォントのみ使用（CORS回避・オフライン動作）。
- **状態保持**：すべてメモリ内（ブラウザストレージ不使用）。リロードで記録は消える。
- **タイマー**：実時刻（Date.now）基準。終了予定時刻から残りを毎回算出するため、タブ非アクティブや処理遅延でも累積ドリフトしない。
- **入力サニタイズ**：指名メモは改行・タブ・制御文字を空白化、連続空白を1つに圧縮、前後トリム、60字超は「…」省略。
- **エスケープ**：記録リスト表示はHTMLエスケープ済み（タグ混入無害化）。
- **バージョン管理**：`APP_VER` 定数で管理（現在 v1.3.0-toybox）。
- **自己テスト**：起動時に自動実行。画面下部に「セルフテスト n/n 全て通過」を表示。

---

## テスト状況（商用レベル点検）

- 構文・構造：JS構文OK、DOM構造の収支一致、CSS変数クリーン、charset/viewport/lang 指定済み。
- 自己テスト：19/19 全通過（集計・サニタイズ・秒数切替・実時刻タイマーを含む）。
- 連打・状態遷移：10連打・過剰undo・正誤混在の集計、二重スタート防止、pause/resume/reset を確認。
- サニタイズ境界：空・空白のみ・60字・61字省略・HTMLタグ混入を確認。
- メモリ：紙吹雪・うさぎ要素は生成後に必ず削除、多重生成ガードあり。
- アクセシビリティ：入力ラベル、ボタンテキスト、ピンチズーム制限なし、単一ファイル（約23KB）。

### 実機で確認推奨（残課題）

- 淡色の補足テキストのコントラスト（プロジェクター投影時の可読性）。
- クリップボードコピー・バイブレーションの挙動（iOS Safari / Android Chrome）。コードはフォールバック済みで、失敗しても停止しない。
